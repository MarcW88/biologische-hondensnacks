### Conclusion d'intention

## 5. Peut-on malgré tout différencier Beloningssnacks ?

Oui, mais uniquement avec une frontière forte.

### Option de différenciation théorique

`Trainingssnacks`
= récompenses spécialement adaptées aux répétitions fréquentes : très petites, rapides à manger, faciles à portionner.

`Beloningssnacks`
= catégorie plus large de récompenses courtes données ponctuellement : mini-biscuits, strips à casser, crispy rewards, lyophilisés, petits bouchons, etc.

Dans ce scénario, Beloningssnacks deviendrait presque :

> quelle petite friandise choisir comme récompense générale, hors mastication longue et hors objectif dentaire ?

### Problème

Cette frontière n'est pas fortement imposée par la SERP actuelle.

Les acteurs du marché utilisent les termes de façon interchangeable, et certains produits relèvent naturellement des deux catégories.

Sans données de demande montrant un cluster distinct, créer cette frontière serait surtout une construction éditoriale interne.

## 6. Scope produit possible si l'URL était conservée

Le marché permettrait néanmoins un scope crédible.

### Candidats biologiques pertinents

#### Yarrah Biologische Mini Snack
- petit format ;
- 97% viande ;
- sans céréales ;
- explicitement utilisé pour training/récompense ;
- données nutritionnelles publiées.

#### Yarrah Biologische Crispy Rewards met kip
- 100% biologique ;
- 99% poulet bio selon la fiche produit ;
- positionnement explicite comme récompense entre les repas ;
- format plus proche d'une récompense ponctuelle que d'un trainer répété.

#### Yarrah Biologische Trainingssnacks met Kip
- produit explicitement orienté training ;
- candidat naturel pour Trainingssnacks plutôt que Beloningssnacks.

#### Produits naturels de type strips / bites / freezies
Le marché non strictement bio montre une large variété de produits utilisés comme récompenses : strips, freeze-dried cubes, mini-hartjes, trainers et bites.

### Conséquence

Un scope Beloningssnacks pourrait être construit, mais il faudrait éviter de reprendre simplement les trois produits déjà présents sur Trainingssnacks.

## 7. Critères de décision si l'URL était conservée

Les critères devraient différer du workflow de Trainingssnacks.

Priorités potentielles :

1. **occasion d'usage**
   - training répété ;
   - promenade ;
   - récompense ponctuelle ;
   - simple tussendoortje.

2. **taille / portionnabilité**
   - snack prêt à donner ;
   - snack facilement cassable ;
   - quantité par récompense.

3. **texture**
   - soft ;
   - crispy ;
   - dried/freeze-dried.

4. **composition**
   - mono-eiwit ;
   - viande / végétal ;
   - céréales ;
   - additifs.

5. **densité / quantité**
   - particulièrement importante si les récompenses sont fréquentes.

6. **statut biologique**
   - preuve séparée de la simple revendication `natural`.

### Point clé

Ces critères ne suffisent pas à eux seuls à justifier une URL distincte. Ils montrent seulement qu'une page différente est possible si la demande le justifie.

## 8. Evidence-based review / factualité

### Niveau de preuve nécessaire

Pour une future sélection produit :

- composition : fabricant en priorité ;
- label bio : fabricant + certification/claim vérifiable ;
- calories / énergie : uniquement lorsqu'elles sont publiées ;
- taille / texture : description fabricant ou retailer, sans inventer l'expérience d'usage ;
- `hypoallergeen`, `gezond`, `goed verteerbaar` : ne pas reprendre comme faits généraux sans preuve adaptée.

### Risques observés sur le marché

Les retailers utilisent facilement des claims comme :

- gezond ;
- hypoallergeen ;
- goed verteerbaar ;
- goed voor het gebit ;
- veilig ;
- versterkt de band.

Le workflow ne doit pas les transformer en faits démontrés.

### Faux hands-on

Aucun jugement de type `makkelijk in de hand`, `ruikt sterk`, `brokkelt niet` ou `hond vindt dit lekkerder` ne doit être écrit sans preuve expérientielle réelle.
