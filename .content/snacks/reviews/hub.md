# Review — Hub Soorten snacks

## Métadonnées
- URL : `/soorten/`
- Date : 2026-09-19
- Mode : `AUDIT`
- Robots : `noindex,follow`
- Décision : `DEEP_REWRITE`

## Intention et rôle
Le hub doit aider à choisir un type de snack avant d'entrer dans une page de sélection produit. Il ne doit pas être une simple liste de liens.

## État actuel
Le hub contient uniquement un hero générique et six liens vers les sous-catégories. Il n'explique ni la différence entre kauwsnacks, trainingssnacks, beloningssnacks, gedroogde snacks, puppy snacks et tandsnacks, ni dans quelle situation choisir chaque famille.

## Valeur attendue
- expliquer les différences fonctionnelles entre les familles ;
- router vers le bon type de snack ;
- montrer les critères qui changent selon l'usage ;
- éviter de dupliquer les comparatifs enfants ;
- refléter les décisions de consolidation du cluster.

## Blockers
- contenu éditorial insuffisant ;
- meta générique ;
- canonical absent ;
- cluster encore incohérent tant que Beloningssnacks/Trainingssnacks et Puppy snacks/Levensfase ne sont pas arbitrés.

## Verdict
`DEEP_REWRITE`

Le hub mérite de rester, mais sa production doit attendre la décision finale sur les URLs enfants afin de ne pas documenter une architecture qui sera ensuite consolidée.
